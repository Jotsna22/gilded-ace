| 0:35–0:55 | Blue M-1152 info + **The floor** map | “We already saw the move work: M-1152 went from about $119 an hour in Back Forty to about $245 at Main Entrance. The floor map paints Back Forty gold and draws the July paths.” |

## Recording tips
- Use the deployed Streamlit URL (or local `http://127.0.0.1:8501`).
- Period: **Jan–Jun**, zone: **All zones**.
- Keep the cursor moving so judges see the UI is interactive.
- Export 1080p; upload the file (or YouTube/unlisted link) on Devpost.
